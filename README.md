# Nuthouse Studios GitHub Pages

This repository hosts the production and development environment for **Nuthouse Studios**.

It includes:
- A Master Controller Agent (MCA) for maintaining, constructing, and developing database systems.
- Automated CI/CD workflows for build and deployment.
- Organized folders for content, documentation, and source code.

## Structure
- `/content` → Published assets
- `/src` → MCA and database logic
- `/docs` → Developer and architecture documentation
- `/.github/workflows` → Automation and deployment scripts

## Deployment
Push to `main` → triggers build and deploy workflow.
